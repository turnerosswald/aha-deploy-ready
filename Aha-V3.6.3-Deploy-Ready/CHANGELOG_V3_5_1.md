# Aha! 3.5.1 — Make learning feel alive

- Removed three-heart daily strike gating and all lockout UI; unlimited retries.
- Added earned XP momentum (×1.00 to ×3.00) and dynamic awards on every mastered step.
- Carried forward earlier V3.5 XP events and persisted progression.
- Expanded the rock collection from eight to sixteen milestone characters.
- Added a click-to-inspect achievement dialog showing unlock requirements and reward context.
- Earned-rock selection equips the user's profile/avatar immediately.
- Added a dedicated My Profile page and header link.
- Added independently animated card backgrounds, level/XP meters, and subtle gradients.
- Added Friends tab: visible example profiles, local request/block/unblock controls, draft messages, inviting by copied note, homework share and opt-in answer sharing.
- Explicitly labeled the Friends experience as a *local preview*, not actual online social connectivity.
- Added XP/momentum/social unit tests, updated documentation and deployment readiness checklist.
