# V3 design intent

**Product:** Aha! — learning, not answer-chasing.

**One job:** Help a learner understand the next small choice in a homework problem, with context *before* the question, supportive feedback *after* it, and progress that reflects reasoning rather than guesses.

## Four places, no busywork

Home is the only place to begin something new. Guided Practice is a single learning conversation. Library lists existing sessions exclusively. Progress summarizes actual learning with a daily topic, mastered steps, and strongest/next-to-practice concepts. Settings stays minimal.

## Key pedagogy decisions

- READ FIRST before every question; teach the relevant concept without handing over the option.
- One decision per step. Seven for the ladder example.
- Ask for the learner's *why*. Correct option + unrelated text is not mastery.
- Give a specific nudge, allow refinement, and count actual wrong options toward a three-per-day challenge limit. Never punish asking for help.
- Hints and full explanations are always available, including when the limit is reached. Skips don't earn mastery.
- AI-generated prompts are graded semantically only with the configured API. Bundled demos work offline with transparent rule checks.

## Character and direction

A bold indigo, yellow, coral, mint and blue visual vocabulary; strong outlines and mostly square shapes; editorial typography; floating bubbles; original illustrated headphone-wearing mascot; generous touch targets and clear keyboard support. Focus mode supports the same lesson and provides a visible escape.

## Explicit MVP non-goals

No friends feed, leaderboards, complex content-management library, fake account syncing, server-verified anti-cheat, or unbounded generic chat transcript. For a real deployment: authentication, durable storage, uploads hardening and stronger accessibility testing.
